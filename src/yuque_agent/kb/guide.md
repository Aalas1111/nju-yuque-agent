> 这个知识库由 **AI agent 自动维护**。你在这里新建一篇文档说明你要借教室，  
agent 会读懂它、整理成标准申请。
>
> 目录按 **申请周期**（周六 00:00 ~ 下周五 23:59）划分，请把申请写进**当前周期**的目录里。
>
> 想看 agent 最近处理了什么？看知识库顶部的 **《Agent 通知》**：本周期内它发出的每一条  
处理通知都在那里，**最新的在最上面**。
>

## 一、三步就能提交
1. 打开**当前申请目录**（形如 `0919-0925`，表示 **9/19 周六 ~ 9/25 周五** 这个周期），  
用知识库文档模板新建一篇文档。
2. **标题写活动名称**（如「新生见面会」「思维训练营第 3 期」）。
3. 填好正文的字段，然后把**第一行** `【草稿】…` **整行删掉**，保存。

删掉那一行之后，agent 一两分钟内就会来处理，结果会发到**社团 QQ 群**和 [Agent通知]({{notice_url}}) 。

> 想先存成草稿？那就留着第一行别动。**agent 永远不会碰带草稿标记的文档。**
>

## 二、要填的字段
```plain
申请人：
活动日期：
活动时间：
校区：
教学楼：
教室：
人数：
```

| 字段 | 必填 | 说明 | 例子 |
| --- | --- | --- | --- |
| 申请人 | ➖ | **你的名字，可不填**。不填不影响受理、也不影响通知；填了是给以后「按人精确通知」用的 | cac |
| 活动日期 | ✅ | 必须距离今天2-9天后 | `2026-09-23` |
| 活动时间 | ✅ | 开始-结束 | `16:10-18:00` |
| 校区 | ✅ | 鼓楼 / 浦口 / 仙林 / 苏州 | `仙林` |
| 教学楼 | ➖ | 不填就随机 | `仙II区` |
| 教室 | ➖ | 不填就随机 | `仙II-101` |
| 人数 | ➖ | 不填按 30 人算 | `25` |


**写得随意一点没关系。** agent 看得懂人话，比如说cac曾经发过这样的信息也成功通过了：

> 仙林下周三晚上八点借教室，常用的那间就行，两个小时。
>

**教学楼和教室只是「意向」。** 学校的系统本来就不保证一定分配到哪一间。  
下游的借用程序会自己去查空闲教室：意向教室被占了，就退回到**同一时段、同一教学楼**里的随机空闲教室。

> 教学楼请写学校系统里的名字（如 `仙II区`、`逸夫楼A区`），别写「一号楼」这种自创叫法。  
agent会尝试处理不规范的信息，但是实在认不出来的名字会被当成「不限」。
>

## 三、几件你必须知道的事
### 1. 教室必须提前 2 天、最多提前 9 天借
学校系统的限制：**可借日期是「今天 +2 天 ~ 今天 +9 天」**。  
今天和明天借不了；9 天以后的系统还没开放。

### 2. 可借用时间段
**08:00 – 22:20**。其中 **12:00 – 14:00 是吃饭时间，本来就不需要借教室**，  
这段会被自动跳过，不算你的错。

**课间的 10 分钟不用管。** 按你活动的真实起止时间写就行，零头交给 agent 对齐。

### 3. 不要动归档区
**知识库的目录按「申请周期」划分，一个周期 = 周六 00:00 ~ 下周五 23:59，目录名就是这两天的日期。**  
比如 `0919-0925` 就是 9/19（周六）到 9/25（周五）这一个周期。

每个周期的申请都会在周期结束（周六 00:00）之前处理完——因为教室必须提前 2 天、  
最多提前 9 天申请，连周日活动的申请最晚也在周五就提了。所以这一刻既是周期翻转点，也是归档时刻：  
agent 会把**上一个周期的目录移进「归档区」**，并确保**当前周期**的目录已经建好。

**归档区里的东西 agent 一律不再处理**，所以上一周期没赶上就别在那里补了，  
请写进当前周期的目录里。

## 四、你会收到什么样的通知
| 你的文档 | agent 做什么 | 你会收到 |
| --- | --- | --- |
| 要素齐全 | 整理成标准申请交给负责提交的同学 | 「已受理」+ 时间/校区 |
| 写得随意但看得懂 | 自动规范化后同样受理 | 「已受理」+ 它改了什么 |
| 有点可疑但能跑（时间特别长、写了「八点到九点」） | **照样受理**，只提醒一句 | 「已受理」+「请确认」 |
| 确实不能办（超期、超时段、信息缺、标题空） | 不提交 | 说明具体原因 + 怎么改 |
| 看不出这是借用申请 | 不提交 | 温和提示用模板新建 |
| **已受理之后又改了文档** | 改动无效 | 提醒一句 |
| **把已受理的文档删了** | 申请不会撤回 | 提醒「删文档 ≠ 撤回申请」 |

## 五、常见问题
**Q：我删了草稿标记，但一直没收到通知？**  
A：检查三件事：

① 文档确实建在**当前申请目录**里（不是归档区、不是别的知识库）；  
② 第一行的 `【草稿】…` 确实删干净了（只剩半行也算没删干净）；  
③ 标题不是空的。

还不行就在群里 @ 负责人。

**Q：我指定的教室没分给我？**  
A：教学楼/教室只是意向。学校从来不保证一定分配到哪一间；  
借用程序退回到同一教学楼里的随机教室属正常。真非它不可，请直接找负责人。

**Q：能不能借今天/明天的教室？**  
A：不行，系统限制「今天 +2 天 ~ +9 天」这个窗口。真着急请直接找老师。

**Q：两个人想前后半场共用一间教室怎么办？**  
A：**写在同一篇文档里**（标题写清是哪两个活动、时间怎么分），agent 会当成一次申请。  
拆成两份反而容易冲突。申请人写不写、写谁都可以（通知发在群里）。

**Q：我忘了写「申请人」，会有影响吗？**  
A：不会。受理和通知都不看这一行——但是如果cac想找人可能找不到你。  
**已经受理的文档不要再回头补**：一改就锁定为「改动无效」。
