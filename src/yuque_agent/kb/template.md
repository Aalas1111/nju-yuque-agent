## 填写说明

1. **文档标题就是活动名称**（如「新生见面会」「思维训练营第 3 期」）。
   不要用「无标题文档」。
2. 填完把**第一行的 `【草稿】…` 整行删掉**再保存——注意是**整行删干净**，
   只删掉 `【草稿】` 四个字的话 agent 仍然会当草稿处理。
3. 字段名不要改，冒号后面要有内容（教学楼、教室、人数可以空着）。
   **「申请人」那一行要写你自己的名字**（或者你希望收到 QQ 通知的那个人的名字）——
   程序靠它决定通知发给谁。写错一个字、或用昵称，就很可能收不到任何消息。
4. 日期写 `2026-09-23`，时间写 `16:10-18:00`。
   写「下午4点到6点」「四点到六点」也能认，但建议用 24 小时制。
5. 校区填 `鼓楼` / `浦口` / `仙林` / `苏州`。
6. 教学楼、教室不填就随机分配；人数不填默认按 30 人算。
7. **可借日期是「今天 +2 天 ~ 今天 +9 天」**：今天和明天借不了，9 天以后的系统还没开放。
8. 两个活动要共用一间教室，**写在同一篇文档里**，不要拆成两篇。

> agent 的处理结果会通过**社团 QQ 群/私聊**告诉你，它**不会改动这篇文档**。
